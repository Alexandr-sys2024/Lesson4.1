# Lesson4.1

## 📌 Описание проекта
Lesson4.1 — это система управления задачами, разработанная на Python.
Проект демонстрирует принципы ООП, работу с датами и управление списком задач.

## 🚀 Функционал
- 📌 **Класс `Task`** — представление задачи с описанием, сроком выполнения и статусом.
- 📋 **Класс `TaskManager`** — управление списком задач:
  - ➕ **Добавление задачи**
  - ✅ **Отметка выполнения**
  - 🔍 **Вывод списка всех задач**
  - ❌ **Вывод невыполненных задач**

## 🛠 Установка и запуск
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Alexandr-sys2024/Lesson4.1.git
   cd Lesson4.1
   ```
2. Запустите скрипт:
   ```bash
   python main.py
   ```

## ✅ Пример работы
```bash
Все задачи:
1. Купить продукты (срок: 20-09-2024) - Не выполнено
2. Написать отчет (срок: 18-09-2024) - Выполнено

Невыполненные задачи:
Купить продукты (срок: 20-09-2024) - Не выполнено
```
